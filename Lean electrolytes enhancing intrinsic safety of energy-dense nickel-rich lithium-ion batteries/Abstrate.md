# 貧電解液策略提升高能量密度鋰離子電池安全性研究摘要

> **期刊：** Journal of Energy Storage (Elsevier)  
> **體系：** 1.1 Ah NCM91 || Gr@5%SiO 軟包電池  
> **關鍵詞：** Lean Electrolyte, Thermal Safety, NCM91, SiO Anode, Pouch Cell

---

## 📌 摘要

本研究針對高能量密度（>300 Wh/kg）鋰離子電池，系統性探討「貧電解液（Lean Electrolyte）」策略對本徵安全性的影響。通過在 **1.5–4.5 g·Ah⁻¹** 範圍內設置 8 個注液量梯度，確定了 **1.8 g·Ah⁻¹** 為 1.1 Ah NCM91||Gr@5%SiO 軟包電池的最佳平衡點：在熱失控峰值溫度降低 **181.2 °C** 且無爆炸的前提下，300 圈循環保持率仍達 **88.5%**（與富液態相當）。低於此閾值則因潤濕不足導致乾區與阻抗激增，性能急劇衰減。

---

## 🔬 核心發現

### 熱安全性對比（DSC + Hot-box）

| 指標 | 4.5 g·Ah⁻¹（富液） | 1.8 g·Ah⁻¹（貧液） | 變化 |
|------|---------------------|---------------------|------|
| 負極-電解液放熱量 | 3959 mJ | 2415 mJ | **−39.0%** |
| 正極-電解液放熱量 | 844 mJ | 610 mJ | **−27.7%** |
| 熱失控峰值溫度 | ~450 °C | ~269 °C | **−181.2 °C** |
| 質量損失 | 31.1% | 25.0% | ↓ |
| 失效模式 | 劇烈燃燒/爆炸 | 僅火花，無爆炸 | ✅ 安全 |

### 電化學性能對比

| 指標 | 4.5 g·Ah⁻¹ | 1.8 g·Ah⁻¹ | 1.5 g·Ah⁻¹ |
|------|-----------|-----------|-----------|
| 300圈容量保持率 | 89.1% | **88.5%** | 急劇衰減 |
| SEI 穩定性 | 良好 | 良好 | 惡化 |
| 倍率性能 | 正常 | 正常 | 嚴重受限 |
| EIS 阻抗增長 | 低 | 低 | R_sei/R_ct 激增 |

> ⚠️ **關鍵閾值：** <1.8 g·Ah⁻¹ 時出現不可逆乾區，導致局部過充與鋰枝晶風險。

### 電解液規格

| 組分 | 詳情 |
|------|------|
| 溶劑體系 | EC : EMC = **3 : 7** (vol%) |
| 鋰鹽 | **1.0 M LiPF₆** |
| 添加劑 | **2 wt%** 商業混合添加劑（proprietary） |
| 供應商 | 蘇州多氟多新能源科技有限公司 |

### 注液量梯度設計
共設置 8 個梯度，覆蓋從極端貧液到富液的全範圍：
1.5 / 1.8 / 2.0 / 2.5 / 3.0 / 3.5 / 4.0 / 4.5 g·Ah⁻¹
- 對應單顆電芯絕對注液量：**1.65 g – 4.95 g**
- 商業基準線：2.5–4.0 g·Ah⁻¹
- 本研究最佳點：**1.8 g·Ah⁻¹**

## 📚 貧電解液文獻回顧與研究定位

### 領域現狀
- **商業標準：** 2.5–4.0 g·Ah⁻¹（過量以保證潤濕與壽命，但犧牲能量密度並增加安全風險）。
- **研究趨勢：** 向 <2.0 g·Ah⁻¹ 推進，以提升體積/重量能量密度並降低電解液成本。

### 三大技術瓶頸
1. **潤濕性不足：** 乾區導致離子傳輸受阻、局部電流密度過高、鋰枝晶生長。
2. **界面穩定性惡化：** 溶劑加速消耗 → SEI/CEI 持續修復增厚 → 阻抗上升 → 容量衰減。
3. **動力學限制：** 高倍率或低溫下極化顯著增大，放電容量保持率遠低於富液電池。

### 現有解決方案及其局限

| 策略 | 局限性 |
|------|--------|
| 低黏度溶劑 / 新型添加劑 / 高濃度電解液 | 常犧牲安全性或增加成本；多基於扣式電池驗證，缺乏 Ah 級軟包數據 |
| 梯度孔隙率 / 超薄 / 三維集流體電極 | 製程複雜，難以在大規模生產中精確控制 |
| 超聲波 / 真空注液 / 高溫加壓靜置 | 增加製造工序與時間成本 |

### 本研究填補的文獻缺口

| 缺口 | 本研究貢獻 |
|------|-----------|
| 缺乏系統性梯度研究（多僅對比貧/富兩極端） | 提供 **1.5–4.5 g·Ah⁻¹** 八梯度精細映射，確定 1.8 g·Ah⁻¹ 最佳閾值 |
| 安全性與性能權衡數據缺失 | 同步完成 **DSC + Hot-box + 循環 + EIS** 全套測試 |
| 高比能體系驗證不足 | 首次在 **NCM91 + Gr@SiO** Ah 級軟包電池上驗證貧電解液適用性 |

## ✅ 結論與工程指導意義

| 維度 | 結果 |
|------|------|
| 最佳注液量 | **1.8 g·Ah⁻¹** |
| 安全增益 | TR 峰值 −181 °C；失效模式從爆炸降級為火花 |
| 性能保持 | 300 圈 88.5%（與 4.5 g·Ah⁻¹ 的 89.1% 相當） |
| 成本效益 | 電解液用量減少約 **60%**，顯著降低 BOM 成本 |
| 設計框架 | 建立高比能電池「安全-耐久-成本」三維協同優化方法論 |
